The 3 Pivotal MCP Functions

The specialized execution and diagnostic engines that eliminate AI hallucinations.

shiny_validate_code

Deterministic AST visitor inspecting the abstract syntax tree for Shiny-specific antipatterns before code execution. Catches uncalled reactive inputs and duplicate widget IDs across nested layouts.

Line 32: [DUPLICATE_ID] Duplicate input ID 'facility_type' detected. Line 70: [UNCALLED_INPUT] Input 'input.surge_multiplier' accessed without parentheses '()'.

shiny_simulate_app

Boots an in-memory AppSession backed by a MockConnection with SHINY_TESTMODE=1. Simulates client events, unhides observers, flushes reactivity, and returns calculated output values in 25ms.

await simulate_shiny_app( file_path="app.py", inputs={"beds": 200, "vol": 150} ) // Returns {success: true, outputs: {...}}

shiny_inspect_reactive_graph

Parses applications into a topological Directed Acyclic Graph (DAG), mapping dependencies from input sources through @reactive.calc conductors to @render.* endpoints to detect broken reactive links.

{ "inputs": ["beds", "volume", "ratio"], "calcs": ["base_metrics"], "outputs": ["occupancy_kpi", "cost_kpi"] }
